# Restore — Excellence Coaching

Premium Next.js frontend for high-value clients: business leaders, elite performers, athletes, and ambitious adults (typically 40–60) investing in health, clarity, and quality of life.

## Brand palette

- Deep navy `#0B1426`
- Rich gold `#C9A227`
- Off-white `#F7F5F0`
- Charcoal `#1F2937`

## Product paths

1. **Live Personalised Mentorship** (highest priority)
2. **Online Courses**
3. **Books**

## Pages

- `/` — Homepage
- `/about` — Philosophy
- `/programs` — Offer overview + audience
- `/coaching` — Live mentorship detail
- `/courses` — Course catalog
- `/books` — Book catalog
- `/contact` — Consultation / apply form

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Cormorant Garamond + Outfit
